Neon Coast turns any photo into GTA-style multi-panel cover art: pick your photos, crop and position each one per panel, choose a layout and a Vice City sunset or neon colour grade, letter the caption in bold gradient type, and export a PNG in 1080x1080, 1080x1350 or 1920x1080. It runs entirely offline in the browser — photos are read on your own machine and never uploaded — and its three sample scenes are original art drawn for this app.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
